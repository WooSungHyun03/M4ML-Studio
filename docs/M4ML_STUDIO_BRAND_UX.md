# M4ML Studio — 브랜드·디자인·사용성 명세

## 목표
연구 시연 페이지가 아니라 실험 데이터와 결과물을 다루는 프로덕션급 데스크톱 소프트웨어. 자연스러운 한국어와 구체적이고 절제된 인터페이스를 제공한다. 디자이너의 임의 브랜드 생성 대신 `Logo/` 실존 로고를 정체성의 기준으로 삼는다.

## 브랜드 자산 처리
- 설치 전 `Logo/`를 실제 열고 확인한다: 파일별 확장자·해상도·배경 투명성·색공간·비율. 가장 선명한 원본을 선택, 필요 시 **파생된** 앱 아이콘/파비콘만 생성한다. 원본은 보존한다.
- 로고가 밝은 배경용인지 어두운 배경용인지 검증; 단색 변형을 임의로 만드는 대신 합법적/시각적 합리성에 맞는 컨테이너/배경을 사용한다.
- 로고 파일이 없거나 손상됐으면 제품명 텍스트로 폴백하고 `docs/STATUS.md`에 명시. 상상으로 로고를 만들지 않는다.
- 메뉴·윈도우 타이틀·알림·About·스크린샷·설치/실행 아이콘·README 제품명은 `M4ML Studio`. 기술 엔진은 `Object-Aware Loss (2DGS)`라고 명시한다.

## 안티패턴 (금지)
- 보라/파랑 형광 그라디언트, 지나친 반투명/블러/글로우, 무의미한 대시보드 숫자, 채팅봇처럼 보이는 말풍선, 모든 화면을 카드로 중첩, 장식용 이모지, 마케팅용 과장 문장(‘AI 혁신의 시작’ 등), 데이터가 없는데 채워진 더미 그래프.
- 뜻이 불분명한 CTA(‘마법 시작’, ‘다음 여정’), 여러 개의 동일 강조 버튼, 자주 바뀌는 레이아웃, 오류를 토스트 하나로 숨기기.

## 제안 구조
- 최상단: M4ML Studio 로고 / 현재 프로젝트명 / 저장 상태 / GPU 상태 / 도움말.
- 왼쪽: 6단계 진행 내비게이션(필요한 단계만 활성), 진행 단계·완료·가져온 데이터·검증 실패 정확한 구분.
- 가운데: 이미지 그리드 / COLMAP 이미지 분류 / 마스크 캔버스 / 실시간 학습 그래프 / 컬러 Mesh 등 해당 단계의 핵심 결과물 크게 표시.
- 오른쪽: **선택된 항목의 상세 정보와 실제 조작 도구**. 마스크 편집 시 positive/negative 및 undo; Mesh 시 컬러·와이어프레임·카메라 리셋 등 상황 의존적 패널.
- 하단: 상태·진행률·에러 요약·실행 로그 열기. 전문가 설정은 펼치기 영역으로.

## UI 패턴
- 라벨은 행동을 말한다: `사진 가져오기`, `COLMAP 결과 사용`, `마스크 적용`, `학습 시작`, `색상 메시 내보내기`.
- 로딩은 ‘처리 중’으로 뭉뚱그리지 말고 `등록된 카메라 108 / 전체 120` / `GPU: ...` / `5,200 / 30,000 반복` 등 **실측값**으로 표시.
- 검사 결과는 단순 빨강/초록 외 텍스트와 아이콘으로 표현하고 색맹 사용자도 이해 가능하게 한다.
- 단일 기본 행동 + 취소/뒤로/수정 동작. 위험한 건너뛰기 및 덮어쓰기는 명확한 확인 대화상자.
- 1366×768, 1920×1080 실창에서 스크롤/툴바 가림·캔버스 작아짐 여부를 검사. 사진을 크게 보게 하는 집중 모드.
- 키보드: 왼쪽/오른쪽 보기 전환(편집 포커스가 없을 때), Ctrl/Cmd+Z/Shift+Z 취소·재실행, +/- 클릭 모드 토글(제안), Enter 승인 다음, `?` 단축키 안내. 실제 키 충돌/접근성 확인.
- 이미지 캔버스는 pan/zoom/fit/100%, 원본/오버레이/이진 마스크와 경계 모드를 지원; 클릭 좌표는 확대·회전·letterbox·DPR·EXIF 변환 후 정확해야 한다.
- Mesh 캔버스는 첫 오픈 시 자동 fit과 미리보기; 관성 회전 과장 금지, vertex color **기본 ON**.
- 단계 건너뛰기는 ‘기존 결과를 검증해 사용했다’로 표기하고 진짜 실행 성공과 구분한다.

## 모든 화면의 빈 상태와 장애 안내
- 데이터 없음 → 가져오기 버튼과 지원 형식.
- COLMAP 등록 0장 → 왜 진행할 수 없는지와 재시도/데이터 수정.
- 마스크 누락 → 이미지 파일별 누락 목록과 다시 매핑.
- CUDA 없음 / 드라이버 부족 / VRAM 부족 → 실제 진단 정보, 복구 가능한 안내, 실패한 명령 상세 보기.
- Mesh 빈 파일 → ‘추출 실패’와 로그, 기술적인 상세는 펼치기.

## 디자인 검증
각 주요 화면의 before/after 캡처와 1366, 1920 크기 스크린샷을 기록. 바뀐 디자인의 작동 기능(버튼·키보드·접근성·리사이즈)을 UI 테스트로 검증한다. 로고 원본이 미확인일 때는 브랜드 색을 확정했다고 주장하지 않는다.

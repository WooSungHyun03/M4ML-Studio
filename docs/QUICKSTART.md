# 시작 가이드

처음 사용한다면 이 순서대로 진행하세요. 자세한 내용은 **도움말 → 사용 설명서**에 있습니다.

1. **새 프로젝트** (Ctrl+N)를 누르고 사진이 들어 있는 폴더를 선택합니다. 객체 주위를 여러 방향에서 서로 겹치게 찍은 선명한 사진 30장 이상을 권장합니다.
2. 분석 화면에서 찾은 데이터와 **추천 시작 단계**를 확인하고 **프로젝트 열기**를 누릅니다. 이전에 만든 카메라 정합·마스크·학습 결과가 이 사진과 맞으면 그대로 이어받습니다. 원본 폴더는 수정하지 않습니다.
3. **카메라 정합**: 카메라 위치를 계산합니다. 등록에 성공한 사진만 다음 단계에 쓰입니다.
4. **객체 선택**: 사진 한 장에서 객체를 클릭(포함)하고, 배경은 Alt+클릭(제외)으로 뺍니다. 결과가 맞으면 다른 사진으로 전파합니다.
5. **마스크 검토**: 사진마다 확인하고, 틀린 곳은 점이나 붓으로 고칩니다. Space로 확인하고 다음 사진으로 넘어갑니다.
6. **3D 재구성**: 설정을 확인하고 **학습 시작**을 누릅니다. 학습은 직접 승인해야 시작됩니다.
7. **3D 모델**: 완성된 색상 3D 모델을 돌려 보고 **PLY/GLB 내보내기**로 저장합니다.

진행 상황은 아래 **작업 관리자**와 **Console**에서 볼 수 있습니다. 문제가 생기면 **도움말 → 오류 해결 가이드**를 보세요. 단축키는 **도움말 → 단축키 목록**에 있습니다.

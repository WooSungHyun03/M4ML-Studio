# 단축키

입력란에 글자를 입력하는 중에는 아래 단축키가 동작하지 않습니다. macOS 키보드의 Cmd는 Ctrl과 같습니다.

## 전체 (메뉴 단축키)

| 키 | 동작 |
|---|---|
| Ctrl+N | 새 프로젝트 (폴더 선택 → 자동 분석) |
| Ctrl+O | 기존 프로젝트 열기 |
| Ctrl+S | 프로젝트 저장 (마스크 붓 수정이 있으면 저장, 나머지는 자동 저장) |
| Ctrl+Shift+S | 다른 이름으로 저장 (프로젝트 전체 복사) |
| Ctrl+E | 3D 모델 내보내기 (PLY) |
| Ctrl+Q | 종료 (확인 후 실행 중인 작업을 중지하고 파일·기록은 보존) |
| Ctrl+Z / Ctrl+Shift+Z | 실행 취소 / 다시 실행 (마스크 화면) |
| Ctrl+A | 모든 사진 선택 (이미지 화면) |
| Esc | 선택 해제 |
| Ctrl+, | 환경 설정 |
| Ctrl+B | 프로젝트 탐색기 보이기/숨기기 |
| Ctrl+I | Inspector 보이기/숨기기 |
| Ctrl+J | 아래 패널 보이기/숨기기 |
| Ctrl+1 … Ctrl+6 | 이미지 · 카메라 정합 · 객체 선택 · 마스크 검토 · 3D 재구성 · 3D 모델 화면으로 이동 |
| Ctrl+R | 현재 단계 다시 실행 (다시 실행할 수 있는 단계만) |
| F1 | 시작 가이드 |
| F11 | 전체 화면 |

## 이미지 화면

| 키 / 마우스 | 동작 |
|---|---|
| 클릭 | 사진 하나 선택 |
| Ctrl+클릭 | 선택에 추가/빼기 |
| Shift+클릭 | 범위 선택 |
| ← / → | 이전/다음 사진 |
| Enter, 더블클릭 | 크게 보기 |
| Delete | 선택한 사진을 목록에서 제거 (카메라 정합 전, 파일은 삭제하지 않음) |

크게 보기 창: 휠 확대/축소 · 드래그 이동 · 더블클릭 2배 · ←/→ 이전/다음 · 0 화면에 맞춤 · Esc 닫기

## 객체 선택 · 마스크 검토

| 키 | 동작 |
|---|---|
| 1, + | 포함 점 |
| 2, − | 제외 점 |
| 클릭 / Alt+클릭·오른쪽 클릭 | 포함 / 제외 점 추가 |
| Tab | 원본 ↔ 마스크 겹쳐 보기 |
| A, ← / D, → | 이전 / 다음 사진 |
| Enter | 저장·승인 |
| Space | 검토 확인 후 다음 |
| 휠 / Shift+드래그 | 확대 / 이동 |

## 3D 모델 화면 (뷰포트를 클릭해 포커스한 뒤)

| 키 / 마우스 | 동작 |
|---|---|
| 왼쪽 드래그 | 회전 |
| 오른쪽 드래그 | 이동 |
| 휠 | 확대/축소 |
| F | 객체에 맞춤 |
| Numpad 1 / Ctrl+Numpad 1 | 앞 / 뒤 시점 |
| Numpad 3 / Ctrl+Numpad 3 | 오른쪽 / 왼쪽 시점 |
| Numpad 7 / Ctrl+Numpad 7 | 위 / 아래 시점 |
| Numpad 5 | 원근 ↔ 직교 투영 |
| 방향 기즈모의 X·Y·Z 원 클릭 | 해당 축 시점 |

## 3D 모델 · 실시간 렌더

| 키 / 마우스 | 동작 |
|---|---|
| 왼쪽 드래그 / 오른쪽 드래그 / 휠 | 회전 / 이동 / 확대·축소 |
| F | 화면 맞춤 (장면 중심) |
| Home | 시점 초기화 (첫 학습 사진 위치) |

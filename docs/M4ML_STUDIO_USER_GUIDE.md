# M4ML Studio 사용자 안내

> 0.3 이후 데스크톱 편집기 화면 기준의 최신 설명은 [USER_GUIDE.md](USER_GUIDE.md), [SHORTCUTS.md](SHORTCUTS.md), [TROUBLESHOOTING.md](TROUBLESHOOTING.md)를 따릅니다. 아래의 "세 가지 시작 방법"은 폴더 자동 분석으로 대체되었습니다.

M4ML Studio는 Object-Aware Loss (2DGS), COLMAP, 공식 SAM3.1을 사용하는 로컬 연구·평가용 도구입니다. 로그인·클라우드 업로드·텔레메트리 없이 사용합니다. 비상업적 연구·평가 조건이 적용됩니다.

## 설치와 실행

지원 검증 범위는 Ubuntu24.04 x86_64 / RTX4080 16GB / 드라이버580.173.02입니다. 이것은 최소 VRAM 보장값이 아니며 다른 GPU는 진단과 실제 추론 검증이 필요합니다. Python3.10/Torch2.5.1/cu118/NumPy1.24.4 anchor를 자동 변경하지 않습니다.

시스템 준비: NVIDIA 드라이버, COLMAP, GCC/G++11, Git, Python3, Conda(Miniforge 등)가 필요합니다. 설치 프로그램은 호스트 드라이버·시스템 패키지를 변경하지 않습니다. Ubuntu 패키지 관리자에서 이 조건을 먼저 준비하세요. 소스에서 UI를 다시 빌드할 때만 Node22/npm이 필요하며 배포 압축본에는 정적 UI가 포함됩니다.

압축을 새 폴더에 풀고 해당 폴더에서 실행합니다.

```bash
./scripts/install.sh
```

Conda가 검색되지 않으면 `STUDIO_CONDA=/실제/conda/경로 ./scripts/install.sh`로 지정합니다. 환경 설치에는 인터넷과 여유 디스크가 필요합니다. 완료 후 Ubuntu 앱 메뉴의 **M4ML Studio**를 엽니다. 터미널 실행은 설치 경로의 `python3 scripts/launch.py` 또는 소스 폴더에서 `./scripts/start.sh`입니다. 브라우저 URL은 http://127.0.0.1:8765 입니다. 포트 변경은 `STUDIO_PORT=8768`로 지정합니다.

공식 SAM3.1 multiplex 가중치는 라이선스에 따라 사용자가 직접 준비합니다. **환경·도움말 → 체크포인트 위치 지정**에서 신뢰하는 `.pt` 경로를 저장합니다. 파일 존재 확인과 실제 구조·추론 검증은 별개이며, 파일이 없더라도 앱은 열립니다.

## 세 가지 시작 방법

- **원본 이미지부터:** 서로 충분히 겹치는 선명한 사진을 선택합니다. COLMAP을 실행하고 실제 등록된 사진만 마스크·학습에 사용합니다. 매칭 수와 등록 수는 다릅니다.
- **COLMAP 결과 사용:** 사진과 `sparse/0/{cameras,images,points3D}.bin` 또는 `.txt`가 포함된 폴더를 선택합니다. 다른 모델 번호, `distorted/sparse/`, `input/`도 감지합니다. 필요하면 상대 경로를 직접 지정하고 한 재구성 그룹을 선택합니다. 기존 포즈를 재추정하지 않습니다. 왜곡된 카메라는 왜곡 보정만 실행합니다.
- **COLMAP + 마스크 사용:** 위 데이터와 등록 사진별 마스크를 선택합니다. 기본 의미는 흰색255=대상, 검정0=배경입니다. 크기·이름·채널 불일치를 파일별로 확인하세요. 알파 채널, 전경 반전, 명시적127 임계값 정규화는 원본을 보존한 복사본에서 적용합니다. 유효한 마스크만 명시적으로 검토를 생략할 수 있습니다. 학습 시작 승인은 항상 별도입니다.

잘못된 마스크를 가진 C 데이터는 학습을 차단합니다. 파일을 수정해 새로 가져오거나 **카메라만 사용하고 마스크 다시 생성**을 선택하세요. 서로 다른 재구성 그룹을 합치지 않습니다. EXIF 회전 사진은 COLMAP에 사용한 픽셀 방향과 맞아야 합니다.

## 마스크와 학습

대상을 포함할 점과 제외할 점을 클릭하면 자동으로 SAM3.1 추론을 예약합니다. 점은 즉시 표시되며 실제 GPU 계산 중에는 **업데이트 중**을 표시합니다. 연속 클릭의 이전 결과는 적용하지 않습니다. 모델을 처음 로드할 때 수십 초 걸릴 수 있으며 계산 완료 시간을 보장하지 않습니다. 오류가 나면 점과 직전 정상 결과를 보존하므로 재시도할 수 있습니다.

붓·지우개는 로컬 픽셀 편집이며 매 획마다 GPU 추론하지 않습니다. 저장·승인 후 다음 사진으로 이동합니다. 초기 대상 확인 후 전체 전파, 이후 주변 미검토 사진 전파는 범위를 확인하고 명시적으로 실행합니다. 다른 승인 마스크는 보호됩니다. 넓은 시점 변화와 가림은 전파 오류를 만들 수 있으므로 결과를 확인하세요.

Ctrl+Z / Ctrl+Shift+Z는 현재 점 또는 붓 도구의 기록을 취소·재실행합니다. 방향키는 사진 이동, +/−는 점 모드, Shift+드래그는 이동, 휠은 확대, Enter는 저장·승인입니다. 브러시 미저장 변경은 이동 경고가 표시됩니다.

학습 준비에서 GPU·마스크·해상도·반복 수를 확인하고 **학습 시작**을 승인합니다. 기본30000회이며 기존 손실/가지치기 알고리즘을 사용합니다. OOM 시 다른 GPU 작업을 종료하거나 해상도를 직접 낮추세요. 프로그램은 손실 가중치를 임의로 바꾸지 않습니다. 중지는 파일·로그를 보존하며 재시도는 새 실행에 저장합니다.

## 색상 메시와 보관

학습 후 원본 TSDF가 자동 실행됩니다. 기본 **컬러**는 실제 정점 색상을 표시하고, **형상**은 조명이 적용된 단색, **와이어프레임**은 삼각형 구조를 표시합니다. 드래그 회전·오른쪽 드래그 이동·휠 확대·카메라 맞춤을 사용하세요. 색상이 없는 파일은 **색상 없음**이라고 표시합니다. 없는 색을 임의로 만들지 않습니다.

원본 컬러 PLY와 표준 선형 정점 색상 GLB를 내보냅니다. 입력 시점이 부족하면 구멍이나 부분 표면이 나올 수 있으며 추출 성공이 완전한 형상이나 수밀성을 보장하지 않습니다. 홈의 **결과 메시 열기**로 기존 PLY/GLB도 확인할 수 있습니다.

새 설치의 프로젝트/런타임은 `$XDG_DATA_HOME/m4ml-studio`(기본 `~/.local/share/m4ml-studio`), 설정은 `$XDG_CONFIG_HOME/m4ml-studio`, 실행 로그/빌드 캐시는 `$XDG_CACHE_HOME/m4ml-studio`에 보관합니다. 기존 Object-Aware Studio 데이터베이스가 있으면 원래 XDG 위치를 그대로 사용합니다. `STUDIO_DATA`로 프로젝트 위치를 지정할 수 있습니다.

업데이트는 다른 버전의 설치 폴더를 만들고 실행 아이콘을 갱신합니다. 같은 버전의 내용이 다르면 기존 파일을 보존하고 설치를 중단합니다. `./scripts/install.sh --uninstall`은 실행 메뉴를 제거하고 앱을 retired-apps로 옮기며 프로젝트·런타임·체크포인트를 보존합니다. 지원용 **진단 파일 저장**에는 프로젝트 경로·사진·마스크·로그 원문을 넣지 않습니다.

GPU 없는 컴퓨터에서 결과 보기만 설치하려면 `./scripts/install.sh --viewer-only`를 사용합니다. 이 모드는 다른 추론 모델로 대체하지 않으며 SAM·학습 기능은 차단합니다. 나중에 GPU 환경을 준비한 뒤 기본 설치를 다시 실행하면 원래 GPU anchor 환경을 구성합니다.

## 0.3 변경 및 현재 배포 범위

이 문서 앞부분의0.2 이력 중 엔진명·설정 메뉴·단축키는 현재 UI 기준으로 다음을 우선합니다. 기본 화면은 작업명으로 표시하고 **설정 → 고급 정보**에서 실제 모델/버전/경로를 확인합니다. 모델은 **설정 → 모델 파일**에 지정합니다. [공식 SAM 안내](https://github.com/facebookresearch/sam3)의3.1 multiplex 가중치를 이용 조건에 따라 직접 취득하세요. 배포본에 가중치는 없습니다.

카메라 엔진은 Ubuntu24.04/glibc2.39용 GPU COLMAP4.2.1이 내장됩니다. 시스템 COLMAP 설치는 필수 경로가 아니며 사용자 고급 설정이 없다면 내장본이 우선입니다. 기본 특징점·매칭은 GPU, mapper/왜곡 보정은 CPU입니다. Ubuntu22.04에서 이 바이너리를 실행할 수 있다고 보장하지 않습니다. 정확한 설치 절차는 최신 README를 따릅니다.

캔버스의 `1/2`는 포함/제외, `A/D` 또는 방향키는 이전/다음, `Space`는 검토 확인 후 다음, `Tab`은 원본/오버레이, `Ctrl+Z/Ctrl+Shift+Z`는 현재 도구의 되돌리기/다시 실행, `Shift+드래그`는 이동입니다. 붓은 **수정 저장**을 눌러야 프로젝트에 반영됩니다. 점은 자동 저장·재추론됩니다.

학습 일시정지 뒤 같은 입력이면 기본2500회 저장 지점부터 GUI에서 재개할 수 있습니다. 반복 수는 절대값이며 재개 로그도 원래 목표 횟수를 표시합니다. 기존 결과를 보존한 새 실행에 저장하고 유효한 부분 checkpoint만 사용합니다.

**내부 연구·평가 빌드이며 공개·상업 재배포는 보류**합니다. 내장47개 라이브러리 고지가 추가됐지만 SuiteSparse 소스 제공·재링크 및 결합 라이선스 검토는 미완료입니다. 법률 검토 완료로 주장하지 않습니다. NOTICE와 M4ML_STUDIO_LICENSES.md를 확인하세요.

# M4ML Studio 사용 설명서

M4ML Studio는 여러 방향에서 찍은 사진으로 객체 하나의 **색상 3D 모델**을 만드는 Ubuntu 데스크톱 프로그램입니다. 모든 계산은 이 컴퓨터의 NVIDIA GPU에서 실행되고, 사진과 결과는 컴퓨터 밖으로 나가지 않습니다. 비상업적 연구·평가 용도로만 사용할 수 있습니다.

## 1. 실행

- Ubuntu 앱 메뉴에서 **M4ML Studio**를 누르거나 설치 폴더에서 `python3 scripts/launch.py`를 실행합니다.
- 프로그램은 **자체 창**으로 열립니다. 웹 브라우저는 열리지 않습니다. 내부 계산 서버는 창과 함께 시작되고 창을 닫으면 함께 종료됩니다.
- 이미 열려 있을 때 다시 실행하면 기존 창이 앞으로 나옵니다.
- 창 크기와 위치, 패널 배치, 테마는 다음 실행 때 그대로 복원됩니다.

## 2. 프로젝트 시작

시작 화면에는 두 가지만 있습니다.

### 새 프로젝트

1. **새 프로젝트**를 누르고 작업할 폴더를 선택합니다. 사진만 있는 폴더도, 이전에 만든 결과가 섞인 폴더도 됩니다.
2. 프로그램이 폴더를 읽기 전용으로 분석합니다. 사진, 카메라 정합 결과(COLMAP sparse), 왜곡 보정 사진, 마스크, 학습 결과, 체크포인트, 3D 모델, M4ML 프로젝트 정보를 찾습니다.
3. 분석 화면에서 무엇을 찾았는지, 각 항목이 **실제로 쓸 수 있는지**, 그리고 **추천 시작 단계**와 그 이유를 확인합니다.
   - 파일이 있다는 것만으로 통과시키지 않습니다. 카메라 결과는 파일을 실제로 읽어 사진 이름과 맞는지 확인합니다. 마스크는 이름과 크기를 사진과 하나씩 대조합니다. 학습 결과는 저장된 카메라 위치를 이 폴더의 카메라 정합 결과와 비교합니다.
   - **다른 사진 세트에서 나온 학습 결과나 모델은 연결하지 않고** 문제 목록에 이유를 표시합니다.
4. **프로젝트 열기**를 누르면 쓸 수 있는 결과를 이어받고 추천 단계에서 시작합니다. 이미 끝난 단계는 다시 계산하지 않습니다.

경로를 직접 지정해야 하는 특별한 경우에는 분석 화면의 **고급: 사용할 데이터 직접 지정**에서 사진·카메라·마스크 폴더를 고를 수 있습니다.

**원본 보호:** 선택한 폴더의 파일은 수정하거나 지우지 않습니다. 필요한 파일은 프로젝트 폴더에 복사한 뒤 사용합니다.

### 기존 프로젝트 열기

시작 화면의 최근 프로젝트 목록에서 프로젝트를 누르거나, **기존 프로젝트 열기**로 M4ML 프로젝트 폴더를 선택합니다. 중간에 멈춘 작업은 마지막으로 검증된 단계부터 이어집니다.

## 3. 화면 구성

| 위치 | 내용 |
|---|---|
| 맨 위 메뉴 | 파일 · 편집 · 보기 · 작업 · 창 · 도움말 |
| 프로젝트 막대 | 프로젝트 이름, 저장 상태, 현재 단계 실행/중지, GPU 사용량 |
| 작업 탭 | 이미지 → 카메라 정합 → 객체 선택 → 마스크 검토 → 3D 재구성 → 3D 모델 |
| 왼쪽 | 프로젝트 탐색기: 사진, 카메라, 마스크, 학습 결과, 체크포인트, 모델, 내보내기 파일. 검색과 "문제만 보기"를 지원하고, 두 번 클릭하면 해당 작업 화면으로 이동합니다 |
| 가운데 | 현재 단계의 작업 화면 (사진 목록, 마스크 편집기, 3D 뷰포트 등) |
| 오른쪽 | Inspector: 선택한 항목이나 현재 단계의 정보와 설정 |
| 아래 | 콘텐츠 · 작업 관리자 · Console(실제 실행 기록) · GPU Monitor |
| 맨 아래 | 상태 표시줄 |

패널 경계를 끌어 크기를 바꾸고, **보기**/**창** 메뉴나 Ctrl+B · Ctrl+I · Ctrl+J로 숨길 수 있습니다. **창 → 레이아웃 저장 / 불러오기 / 초기화**, **보기 → 기본 레이아웃 복원**을 사용할 수 있습니다.

## 4. 단계별 사용법

### 이미지

- 객체 주위를 여러 방향에서 서로 겹치게 찍은 선명한 사진이 필요합니다(30장 이상 권장). JPG · PNG · TIFF를 지원합니다.
- 검색, 정렬(가져온 순서 · 이름 · 해상도), 경고/오류 필터, 카메라 정합 뒤에는 **정합됨/미정합** 필터를 사용할 수 있습니다.
- Ctrl/Shift+클릭으로 여러 장을 고르고, 카메라 정합 전이라면 **제거**(Delete)로 목록에서 뺄 수 있습니다. 파일 자체는 지우지 않습니다.
- 사진을 두 번 클릭하거나 Enter를 누르면 원본 해상도로 크게 볼 수 있습니다.

### 카메라 정합

GPU로 특징점을 찾고 사진끼리 연결한 뒤 카메라 위치를 계산합니다. **특징점 매칭 성공과 카메라 등록 성공은 다릅니다.** 등록에 성공한 사진만 이후 단계에 쓰입니다. 결과는 **등록된 사진** 목록이나 **3D 포인트 · 카메라** 보기로 확인합니다. 3D 보기에서 카메라 사각뿔을 클릭하면 해당 사진이 선택됩니다.

### 객체 선택

사진 한 장에서 객체를 클릭하면(포함 점) 자동으로 객체 영역을 계산합니다. 배경은 Alt+클릭이나 오른쪽 클릭(제외 점)으로 뺍니다. 결과가 맞으면 나머지 등록 사진으로 전파합니다. 사진 사이 시점 차이가 크거나 가려진 부분이 있으면 전파가 틀릴 수 있으니 다음 단계에서 확인하세요.

### 마스크 검토

사진마다 마스크를 확인하고, 틀린 곳은 점을 다시 찍거나 붓/지우개로 고칩니다. 붓 수정은 **수정 저장**을 눌러야 반영됩니다. 쓸 수 있는 마스크라면 남은 검토를 명시적으로 건너뛸 수 있습니다.

### 3D 재구성

GPU, 반복 수(기본 30,000회), 마스크 상태를 확인하고 **학습 시작**을 누릅니다. 학습은 사용자가 승인해야만 시작됩니다. 진행률, 실제 손실 값, 실행 기록이 표시됩니다. **일시정지**하면 마지막 저장 지점(기본 2,500회 간격)부터 이어서 학습할 수 있습니다.

### 3D 모델

화면 위쪽에서 **실시간 렌더 | 메시**를 고를 수 있습니다.

**실시간 렌더**는 메시로 변환하기 전, 학습된 결과 자체를 자유로운 시점에서 렌더링합니다. 학습이 끝나면 자동으로 사용할 수 있고, 프로젝트를 다시 열어도 마지막 학습 결과를 불러옵니다.
- 조작: 왼쪽 드래그 회전, 오른쪽 드래그 이동, 휠 확대/축소, **화면 맞춤**(F), **시점 초기화**(Home, 첫 학습 사진 위치)
- 학습 시점: ‹ › 버튼으로 학습 사진을 찍은 위치로 이동
- 렌더 모드: 색상 · 불투명도 · 깊이 · 법선 · 객체 점수(객체로 학습된 정도)
- 기타: 전체 화면, 스크린샷(PNG). Inspector에 Gaussian 수, 학습 반복, 렌더 해상도, 응답 지연이 표시됩니다.
- GPU 사용: 실시간 렌더는 GPU를 사용합니다. 학습·3D 모델 생성·객체 선택이 시작되면 자동으로 멈추고, 다른 화면으로 이동하면 GPU 메모리를 반환합니다.

**메시** 뷰포트에서는 다음 기능을 사용할 수 있습니다. 학습이 끝나면 3D 모델(메시)을 자동으로 만듭니다.

- 표시 모드: **색상 메시**(기본, 파일에 저장된 색을 그대로) · 정점 색상(조명 적용) · 셰이딩 · 와이어프레임 · 법선 · 포인트 클라우드(모델의 정점)
- 시점: 앞/뒤/왼쪽/오른쪽/위/아래, 원근/직교 투영, 방향 기즈모 클릭, F 맞춤, 카메라 초기화
- 보조: 바닥 그리드, 좌표축, 메시 통계, 밝기와 조명 방향, 포인트 크기, 배경색
- **스크린샷 저장(PNG)**, **다시 불러오기**, **PLY/GLB 내보내기**

시점 이름은 카메라 정합 좌표의 축 기준입니다(앞 = +Z 쪽에서 봄). 크기도 정합 좌표 단위이며 실제 치수가 아닙니다. 촬영되지 않은 면은 구멍이 있거나 매끄럽지 않을 수 있습니다.

## 5. 저장 위치

- 프로젝트·런타임: `~/.local/share/m4ml-studio`
- 설정: `~/.config/m4ml-studio`
- 실행 기록: `~/.cache/m4ml-studio` (**도움말 → 로그 폴더 열기**)

## 6. 처리 엔진 정보

기본 화면은 작업 이름만 보여 줍니다. 실제 사용 중인 모델, 버전, 파일 경로, 라이선스는 **설정 → 고급 정보**에서 확인할 수 있습니다.

문제가 생기면 **도움말 → 오류 해결 가이드**를 보세요.

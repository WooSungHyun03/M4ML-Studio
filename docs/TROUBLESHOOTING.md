# 오류 해결 가이드

문제가 생기면 먼저 아래 패널의 **Console**에서 실제 실행 기록을 확인하세요. **복사** 버튼으로 기록을 복사할 수 있고, **도움말 → 로그 폴더 열기**로 앱 기록(`~/.cache/m4ml-studio`)을 열 수 있습니다. 설치 폴더에서 `./scripts/doctor.sh`를 실행하면 GPU, 드라이버, 런타임, 모델 파일을 점검합니다.

## 프로그램이 열리지 않음

- **창이 뜨지 않고 브라우저 모드 안내가 나옴**: 데스크톱 창 구성요소(PySide6/QtWebEngine)가 설치되지 않았습니다. 설치 폴더에서 `./scripts/setup.sh`(또는 `./scripts/install.sh`)를 다시 실행하세요.
- **"다른 M4ML Studio가 시작 중"**: 이미 실행 중입니다. 잠시 기다리거나 열려 있는 창을 찾으세요.
- **창이 하얗게 보이거나 바로 닫힘**: `~/.cache/m4ml-studio/desktop.log`와 `launcher.log`를 확인하세요. 원격 데스크톱이나 가상 머신에서는 그래픽 가속이 없어 3D 화면이 열리지 않을 수 있습니다.

## 새 프로젝트 분석 결과가 예상과 다름

- **카메라 정합 결과가 "사용 불가"**: `cameras`, `images`, `points3D` 세 파일이 모두 있어야 하고, 그 안의 사진 이름이 폴더의 사진과 맞아야 합니다. 분석 화면의 문제 목록에서 맞지 않는 이름 수를 확인하세요.
- **마스크 일부가 빠짐**: 마스크 파일 이름이 사진 이름(확장자 제외 가능)과 같고 크기가 사진과 같아야 합니다.
- **학습 결과나 3D 모델이 연결되지 않음**: 결과에 저장된 카메라 위치가 이 폴더의 카메라 정합 결과와 다르면 다른 사진 세트에서 나온 것으로 판단하고 연결하지 않습니다. 잘못 섞이는 것을 막기 위한 동작입니다.
- 자동 판단을 바꿔야 하면 분석 화면의 **고급: 사용할 데이터 직접 지정**을 사용하세요.

## GPU

- **GPU를 찾을 수 없음**: `nvidia-smi`가 동작하는지 확인하세요. 프로그램은 드라이버를 설치하거나 바꾸지 않습니다.
- **메모리 부족 (Out of memory)**: 다른 GPU 프로그램을 종료하고(아래 패널 **GPU Monitor**에서 사용량 확인) 다시 실행하세요. 3D 재구성의 고급 설정에서 해상도를 낮출 수도 있습니다. 직전 정상 결과, 점, 기록은 보존됩니다.

## 카메라 정합

- **등록된 사진이 적음**: 흐린 사진, 겹침이 적은 사진, 반사·무늬 없는 표면이 원인입니다. 실패한 위치를 다시 촬영해 추가하는 것이 가장 효과적입니다. 순서대로 찍은 사진이면 **사진 비교 방식 → 인접 비교**가 빠를 수 있습니다.
- **GPU 가속 엔진 없음 안내**: 설치 폴더에서 `./scripts/build_colmap.sh`로 엔진을 설치하거나, 오래 걸리는 CPU 실행을 직접 선택하세요.

## 객체 선택 · 마스크

- **첫 클릭이 오래 걸림**: 처음에는 모델을 읽는 데 수십 초가 걸릴 수 있습니다. 이후에는 모델을 유지합니다.
- **모델 파일 오류**: **설정 → 모델 파일**에서 공식 SAM 3.1 체크포인트 경로를 지정하세요. 배포본에는 가중치가 포함되지 않습니다.
- **다른 사진으로 전파된 마스크가 틀림**: 시점 차이가 크면 생길 수 있습니다. 해당 사진에서 점을 다시 찍거나 붓으로 고친 뒤 저장하세요.

## 3D 재구성 · 3D 모델

- **학습이 중단됨**: 프로젝트를 다시 열면 마지막 저장 지점부터 이어서 학습할 수 있습니다(같은 입력일 때). 사진이나 마스크를 바꾸면 이전 저장 지점을 쓰지 않고 새로 학습합니다.
- **3D 화면이 비어 있음**: 뷰포트의 **다시 불러오기**와 **객체에 맞춤(F)**을 눌러 보세요. 그래도 비어 있으면 Console에서 3D 모델 생성 기록을 확인하세요.
- **색상이 없다고 표시됨**: 파일에 정점 색상이 없는 경우입니다. 프로그램은 없는 색을 임의로 만들지 않습니다.
- **구멍이 있거나 표면이 거침**: 촬영되지 않았거나 가려진 부분입니다. 그 방향의 사진을 추가해 다시 만드세요.

## 지원 요청

**설정 → 처리 장치**의 **진단 파일 저장**을 사용하세요. 진단 파일에는 사진, 마스크, 프로젝트 경로, 로그 원문이 들어가지 않습니다.

## 배포 형식 선택 원칙
1. 실제 배포 가능한 경로가 우선이다. CUDA extension 런타임/ABI 제약과 COLMAP/native deps 때문에 AppImage 또는 Electron만으로 단일 실행 파일이 자동 완성되는 것은 아니다.
2. 사용자 친화적 옵션: `.deb` 또는 portable app directory/tarball + `install.sh` + `.desktop` + 로컬 UI 정적 번들 + 버전 잠금 환경. 실제 버전 호환성 검증 후 선택한다.
3. 소스코드, 체크포인트, 학습 데이터를 한 zip에 묶어 무분별하게 재배포하지 않는다. 서드파티 이용조건 및 크기를 고려한 1회 다운로드/캐싱/경로지정 전략을 선택한다.
4. GPU 드라이버는 보통 호스트 제공. 드라이버 시스템 변경을 자동/무단 강행하지 않는다. `.deb` 설치 실패 상황 및 부족 권한을 다룬다.
5. 실질적인 신규 사용자 설치 테스트를 통과하지 못했다면 `개발용 프리뷰`로 표시하고 `일반 배포 완료`라고 말하지 않는다.
